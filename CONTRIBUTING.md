# Contributing to STEMEd+ Commons

Thank you for helping. These are the defaults for every STEMEd+ Commons repository; a repository
with its own `CONTRIBUTING.md` has more specific instructions, so check there first.

## Suggest a listing

Open a new issue in the board's repository and pick the matching template (for example,
"Suggest a conference" or "Post a job"). The form asks for everything we need.

## Report an error

Open an issue in the board's repository using the "Update" or "Wrong listing" template if there is
one, or a blank issue if not. Tell us which listing, what is wrong, and a link to the correct
information.

## Propose a code change

1. Fork the repository.
2. Make your change on a branch in your fork, and run the tests if the repository has them.
3. Open a pull request describing what changed and why.

A maintainer will review it before it is merged.

## What a listing can contain

* **Public information only.** Every listing must come from a public source, such as an official
  call, job posting, program page, or conference website, and link to it.
* **No personal data beyond what the person chose to share.** Do not add contact details or other
  information about a person unless they published it for this purpose themselves.

## Using AI tools

Board submissions may be drafted with help from AI tools, as long as you have checked that the
submission is accurate and matches its source. You are responsible for what you submit.

## Code of Conduct

Everyone taking part is expected to follow our [Code of Conduct](CODE_OF_CONDUCT.md).
